\# 🏦 Sistema Bancario Java



A console-based banking management system developed in Java to practice and apply object-oriented programming, data management, validation, and problem-solving principles.



\## 📋 About the Project



This application simulates a banking system where multiple customers and bank accounts can be managed through an interactive console menu.



The system allows users to create, search, consult, modify, and delete customers, as well as perform different banking operations such as deposits, withdrawals, and transfers between accounts.



The project was designed to strengthen Java programming skills by applying object-oriented programming concepts to a practical scenario.



\## 🚀 Features



\* 👥 Manage multiple bank customers

\* ➕ Create new customers

\* 🔎 Search customers by account number

\* 📋 Display registered customers

\* 👤 Consult individual account information

\* 💰 Deposit money into an account

\* 💸 Withdraw money from an account

\* 🔄 Transfer money between accounts

\* 🗑️ Delete customers

\* ✅ Validate transaction amounts

\* 🛡️ Prevent withdrawals when there are insufficient funds

\* 🚫 Prevent transfers between the same account

\* 📊 Manage customer data using Java arrays

\* 🎮 Interactive console-based menu



\## 🧠 Object-Oriented Programming

\* \*\*Classes and objects\*\*

\## ▶️ How to Run



1\. Clone the repository.

2\. Open the project in IntelliJ IDEA or another Java IDE.

3\. Make sure a compatible JDK is installed.

4\. Run `Main.java`.

5\. Use the console menu to interact with the banking system.
